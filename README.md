# Stud.IPSync

Synchronisiert neue Dateien aus Stud.IP automatisch nach Google Drive.

**[Stud.IPSync für Windows herunterladen (.exe)](https://github.com/wohlfahrt-florin/StudIPSync/releases/download/v1.0.0/StudIPSync.exe)** · v1.0.0 (Vorabversion)

## Start

1. `StudIPSync.exe` starten und bei Stud.IP anmelden.
2. Im Browser mit Google anmelden, einen Drive-Ordner auswählen und in der App auf **Speichern** klicken.
3. Optional die tägliche Synchronisierung aktivieren oder **Jetzt synchronisieren** wählen.

Die Synchronisierung läuft nur von Stud.IP nach Google Drive und löscht dort keine Dateien. Anmeldedaten und Synchronisierungsstatus bleiben lokal auf deinem Computer.
