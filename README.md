# Stud.IPSync v1.0.0

## Schnellstart

1. **[Stud.IPSync v1.0.0 herunterladen](https://github.com/wohlfahrt-florin/StudIPSync/releases/tag/v1.0.0)**
2. **Bei Stud.IP anmelden**, wenn die Anwendung danach fragt.
3. **Mit Google anmelden** und den Zielordner in Google Drive auswählen.
4. Auf **Speichern** klicken.
5. Fertig: Neue Dateien aus Stud.IP werden automatisch nach Google Drive synchronisiert.

Über **Jetzt synchronisieren** kann die Übertragung jederzeit manuell gestartet werden. Die tägliche automatische Synchronisierung lässt sich im Hauptfenster aktivieren.

Die Anwendung löscht keine Dateien aus Google Drive.
